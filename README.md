# Advent of Code

Solutions to [Advent of Code](https://adventofcode.com), 2019 onwards, in a mix of languages: mostly Python and C, with some Rust, Go, and a few in arm64 assembly just for fun.

```
2019/day01/solution.s     one folder per day, one solution file
```

Run a day on its input:

```sh
python3 aoc.py 2019 1     # download the puzzle input (needs your session cookie in ~/.config/aoc-session)
python3 run.py 2019 1     # build if needed and run: prints the answers
```

Inputs aren't included: the puzzle creator asks people not to share them, so each person uses their own.
